# Inkead

> A distraction-free personal offline reading sanctuary and luxury e-reader for desktop and mobile.

## Features

- **Universal Format Support**: EPUB, PDF, CBZ/CBR (Graphic Novels & Manga), MOBI, AZW3, FB2, RTF, HTML, TXT, and Markdown.
- **Editorial Wikipedia Reader**: Turn any Wikipedia article into a book with high-resolution illustrations, clean typography, chapter sections, and zero boilerplate.
- **PWA & Standalone App**: 100% offline-first progressive web app. Installable on Windows, macOS, iOS, and Android.
- **Calm Typography & Theming**: Custom optical grade typography (Google Sans, Editorial Serif, Classic Book, Monospace) with 9 curated color palettes, OLED dark mode, and butter-smooth theme transitions.
- **Annotations & Marks**: Select text to highlight, take margin notes, or place visual pin marks anywhere on pages and chapters.
- **Integrated Lexicon**: Instant dictionary definitions with multi-tier lookup (Free Dictionary, Wiktionary, Wikipedia summaries, and audio pronunciations).
- **Ambient Soundscapes**: Built-in sound player with Rain, Forest, Cafe, White Noise, Ocean, and Fireplace audio loops.
- **Private & Local**: All books, files, annotations, and reading progress are stored entirely on your local device.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
